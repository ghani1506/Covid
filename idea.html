COVID-19 Educational Simulation

An Interactive Visualization for Understanding Disease Spread

💡 Project Idea

This simulation was designed as an educational tool to help students, teachers, and the public visualize how an infectious disease like COVID-19 spreads in a community. It simplifies the epidemiological model into five visible states — Susceptible (S), Exposed (E), Infectious (I), Recovered (R), and Vaccinated (V).

Goal: To make abstract public-health concepts (like transmission rate, mask use, or social distancing) more tangible and interactive through simulation and data visualization.

🔬 How It Works

The simulation represents individuals as colored dots moving randomly in an enclosed area. When an infectious individual comes close to a susceptible one, there’s a chance the virus is transmitted. Over time, exposed individuals become infectious, and later recover or gain immunity.

  • Blue — Susceptible (healthy but can get infected)
  • Orange — Exposed (infected but not yet infectious)
  • Red — Infectious (can spread the virus)
  • Green — Recovered (immune after infection)
  • Purple — Vaccinated (reduced risk of infection)

⚙️ Adjustable Parameters

The simulation lets users adjust real-world factors to observe how they change the spread:

  • Population size
  • Mobility (movement speed)
  • Mask usage percentage
  • Social distancing level
  • Transmission probability (β)
  • Incubation & infectious durations
  • Vaccination coverage

These variables make it easy to explore “what if” scenarios — for example, increasing mask usage or lowering mobility can dramatically flatten the curve.

🎓 Educational Applications

  • Science and health classes — to discuss epidemics, infection dynamics, and prevention strategies
  • Mathematics — introducing the concept of exponential growth and rates
  • Data science — linking visual simulations with underlying data models (S-E-I-R-V framework)

🌐 Technology Stack

  • Python (Pyodide) — simulation logic runs directly in the browser
  • JavaScript + HTML Canvas — handles drawing and user interaction
  • GitHub Pages — free hosting for static files
